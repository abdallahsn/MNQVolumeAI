# Research Corpus

This folder stores the Phase 0.5 research and planning corpus.

- `papers/original/` contains inspected non-code source documents copied with original filenames preserved.
- `papers/notes/` is reserved for future review notes.
- `research_catalog.yaml` records source metadata and verification status.
- `claims_registry.md` separates source claims, verified claims, unverified claims, hypotheses, contradicted claims, and rejected claims.
- `research_gaps.md` records missing evidence before implementation.

No source claim in this corpus is accepted as a verified trading fact until independently reproduced with causal, cost-aware, out-of-sample validation in this repository.
